# Hệ thống Thư viện Ảnh / Gallery

- Họ tên: Lê Minh Trang
- Mã sinh viên: DTC245200753

## Giới thiệu
Website quản lý và trưng bày các bộ ảnh nhiếp ảnh.
Khách có thể xem album công khai mà không cần đăng nhập.
Quản trị viên đăng nhập để quản lý album và ảnh.

## Chức năng dự kiến
- Quản lý album ảnh.
- Upload và quản lý ảnh.
- Phân loại ảnh.
- Chia sẻ album.
- Giới thiệu nhiếp ảnh gia và thông tin liên hệ.

## Yêu cầu triển khai
- MySQL và phpMyAdmin.
- Docker Compose và Nginx reverse proxy.
- Prometheus và Grafana để giám sát.
- Loki và Promtail để thu thập log.
- Các biện pháp hardening hệ thống.

Đang khởi tạo dự án và xác định yêu cầu.
